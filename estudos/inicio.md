# O que é um SO?

* Resumo! (Minha concepção do assunto)
    Um **sistema operacional** é o programa que faz o computador poder ser usado. Ele que faz tudo: seta memória, arquivos, cria GUI, faz o que o usuário não deveria saber.

É um software (programa) que controla o computador e o que ele pode fazer. O básico que ele deve fazer é ter a "Capacidade de carregar e executar programas de usuário, fornecendo uma interface de entrada/saída padronizada (independente de hardware) para eles."

Alguns dos critérios básicos de um OS são:

- Gerenciar memória e outros recursos do sistema.
- Impor regras de segurança para os arquivos/programas que forem rodas no sistema.
- Conseguir lidar com múltiplos processos e threads (comandos).
- Abrir e fechar processos/programas do usuário.
- Dar uma interface gráfica e uma API (para dev apps) básica.

Um sistema operacional não é:

- O hardware do compudator.
- Um app (web, jogos, gui, etc.).
- Conjunto de utilitários (gcc, brew, make, etc.).
- Um ambiente de desenvolvimento (dev environment).
- Um GUI (não É, mas PODE TER UM).
